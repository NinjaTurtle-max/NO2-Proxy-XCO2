시드 스터디(42·123·7, 150ep) 결과 cnn_lstm 0.6158±0.0050 vs unet_pconv 0.6140±0.0040 — 평균 차이(+0.0018)가 시드 표준편차보다 작은 통계적 동률. 한쪽을 취사선택하는 대신 두 아키텍처를 모두 고도화하여 벤치마크의 복합 신뢰성을 확보한다. 목표는 변동도 천장 R²=0.7035(현재 도달률 ~88%)와의 잔여 격차 ~0.09의 축소.

2. 아키텍처별 상향 스펙

2-A. CNN-LSTM v4 — core/arch_cnn_lstm_v4.py

요소설계근거
경향(lag) 채널 Δu₁₀, Δv₁₀, ΔNO₂, Δz500 — 프레임 간 1차 차분 4종, C: 11→15 (dataset.py --lag_features, 두 모델 공용) [대기화학] 수송 인과성은 농도가 아닌 변화율에 실림 (이류장 변동·배출 변동·종관 전환)

2-B. UNet-PConv v4 — core/arch_unet_pconv_v4.py

요소설계근거
이중 스트림 (최대 기대 이득) 희소 스트림(y_in·in_mask → PConv) ∥ 밀집 스트림(물리장·계절·경향 → 일반 Conv), 인코더 4단계 각각에서 융합 + 신뢰도 마스크 채널 공급 [PIML] v5는 x*m으로 어디서나 유효한 dense 물리장까지 관측마스크로 0이 되는 구조적 정보 손실. [대기화학] NO₂ 배출 코어가 dense 스트림으로 분리되어 마스크 갱신과 무관하게 구조적으로 보존
첫 희소 블록 k=5 + 분수 마스크 갱신(이진 msum>0 대신 m′=msum/slide 연속 신뢰도) [지구통계] 경계 신뢰도 보존으로 핫스팟 스미어링 억제 (±2격자 ≈ 55 km 국지 문맥)
인코더 심도 3단 다운샘플(H/2·H/4·H/8) — 보틀넥 H/8=15에서 3×3이 원해상도 24격자 커버 [지구통계] 유효 range 58격자 대응, 전체 RF가 range 상회

3. 공통 동적 물리 손실 가중치 — core/losses_adaptive.py

그래디언트-노름 균형 + EMA 댐핑. 에폭 e에서:

λ̂e = ḡdata / (ḡpde + ε),   ḡ• = (1/Ne) Σbatch ‖∇θenc L•‖₂

λpde(e) = clip( ρ·λpde(e−1) + (1−ρ)·λ̂e, [0.05, 5.0] ) · r(e)
  • 댐핑 계수 ρ = 0.9: 시간상수 τ = 1/(1−ρ) = 10 epoch — Phase 2 길이 (150ep 기준 45 epoch)의 ~1/4. 배치 노이즈(epoch당 9 스텝)는 평활, phase 전환은 추적.
  • r(e) = 기존 커리큘럼 램프(P1: 0.05 고정, P2: 0→1 선형, P3: 1). CurriculumScheduler의 lambdas['pde'] 절대값을 본 스케줄러 출력으로 대체 — F3 전례(이중 곱셈) 방지.
  • clip 하한 0.05 = P1 최소 물리 제약 유지, 상한 5.0 = EMA 스케일 정규화 결합 시 발산 방지.
  • AdaptivePhysicsLoss의 SNR 픽셀 가중 = 분포(어디에), 본 스케줄러 = 전역 스케일(얼마나) — 직교라 병존.
  • Trivial Escape 차단 (TrivialEscapeRegularizer로 일원화):
    Lesc = wam·(−log σ²pred) + wvf·E[ max(0, 1 − σpred/σtarget)² ]
    첫 항 = 기존 anti-mean과 동일식(흡수, 중복 부과 금지), 둘째 항 = 분산 하한 — 예측장 표준편차가 관측 타겟 표준편차에 못 미치면 직접 벌점.
